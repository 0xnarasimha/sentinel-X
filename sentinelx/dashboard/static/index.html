Known Limits (§13)

  • First-contact trust (TOFU): protection begins at first contact; an attacker who suppresses the real router before you join can outrun TOFU.
  • Host ↔ gateway scope only: peer-to-peer LAN traffic between two non-gateway hosts is out of scope.
  • IPv4 ARP only: IPv6 NDP/RA spoofing is out of scope.
  • Root on this host: a root adversary can stop the daemon or rewrite files; the chain detects mid-file edits, deletions and reordering — not tail truncation — unless the head hash is anchored externally.
  • VRRP/HSRP: virtual router MACs are accepted only when the gateway was originally learned as a virtual MAC.
